# 界面风格（管理员统一选择）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供邮戳、清爽工作台、多邮箱色标三种完整的界面风格（各有浅色和深色），由管理员在系统设置里统一选择，全站所有页面跟随。

**Architecture:** `style.css` 改为一层语义化 CSS 变量，三种风格各赋一组值，`html[data-theme]` 加 `.dark` 类切换；既有自定义变量保留名字改为引用语义变量，组件里写死的颜色换成变量。风格存在 `setting.ui_theme`，前端启动时先按 `localStorage` 上色再按站点配置校正。标志元素（头像、色条、未读条、斜纹按钮）始终渲染，由 CSS 按风格显示。

**Tech Stack:** Vue 3、Element Plus、SCSS、Pinia；Hono + Drizzle/D1；vitest（后端）、`node --test`（前端纯逻辑）。

**Spec:** `docs/superpowers/specs/2026-11-11-ui-themes-design.md`

**执行前提：** 分支 `feat/ui-themes`（自 `main` 切出）。不要碰 `feat/account-forward`。

## Global Constraints

- 风格值只有三个：`postmark`、`workspace`、`palette`；默认 `workspace`；非法值一律当作 `workspace`。
- 数据库字段 `setting.ui_theme TEXT NOT NULL DEFAULT 'workspace'`，Drizzle 字段名 `uiTheme`，迁移函数名 `v3_6DB`，在 `init()` 里 `v3_4DB` 之后调用。
- `GET /setting/websiteConfig` 返回 `uiTheme`；`PUT /setting/set` 收到非法 `uiTheme` 抛业务错误 `invalidUiTheme`（zh `无效的界面风格` / en `Invalid interface style`）。
- 页面切换风格用 `document.documentElement.dataset.theme`；深色仍用 `html.dark` 类；`localStorage['ui-theme']` 保存上次风格。
- 语义变量名固定（组件只能用这些和 Element Plus 自己的 `--el-*`）：`--font-heading`、`--radius-sm/md/lg`、`--surface-1/2/3`、`--sidebar-bg/text/text-muted/border/active-bg/active-text/hover-bg`、`--compose-bg/text/hover-bg`、`--stripe-a`、`--stripe-b`、`--unread-mark`、`--code-tag-bg/border/text`、`--avatar-N-bg`、`--avatar-N-text`（N = 1..8）、`--chart-1..6`、`--chart-area-from/to`、`--login-gradient`、`--theme-color-meta`。
- 六组色值见 Task 2 的表，实现时逐字照抄。
- 页面布局、功能入口、文案、手机端布局不改。
- 不改 `components/shadow-html`、`utils/icon-utils.js`、`icons/index.js`、`layout/main` 的手机端黑色遮罩、`sys-setting` 的第三方品牌图标色。
- 标题字体只在这些地方用 `var(--font-heading)`：`layout/header` 的 `.breadcrumb-item`、`views/content` 的 `.email-title`、`views/setting` 的 `.title`、`views/sys-setting` 的 `.card-title`、`views/analysis` 的 `.title`、`layout/aside` 的 `.title`（站名）。
- 头像只在 workspace 显示；邮箱色点和邮件色条只在 palette 显示；未读红条和斜纹按钮只在 postmark 显示。

## Review Focus

1. **首屏闪烁**：`index.html` 的启动脚本必须在应用挂载前按 `localStorage['ui-theme']` 设 `data-theme`，否则老用户每次刷新先看到清爽工作台再跳。Task 2 的验证步骤覆盖：改风格后刷新，录屏或连续截图确认第一帧就是对的。
2. **深色模式下 Element Plus 主按钮文字不可读**：palette 深色的主色接近白，`el-button--primary` 默认白字。Task 2 必须在 `html[data-theme="palette"].dark` 下把 `.el-button--primary` 的 `--el-button-text-color` 设为 `#18181B`，Task 7 截图核对系统设置页的"保存"按钮。
3. **站内邮件没有发件人名字时的头像**：`senderInitial('', 'noreply@github.com')` 必须返回 `N`，空地址返回 `?`。Task 4 单测覆盖。
4. **"全部收件"模式下的色条**：同一列表里有多个邮箱时，色条按每行的 `toEmail` 取色，不是按当前选中账号。Task 4 的本地验证用两个账号各收一封信核对。
5. **分析页在切换风格后不重绘**：图表颜色是初始化时读的，管理员保存风格后分析页若已缓存（`keep-alive`）会停在旧色。Task 5 要监听 `settingStore.settings.uiTheme` 重算并 `setOption`，Task 7 核对。
